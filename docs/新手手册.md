# 技能说明 · comfyui-local-zimage（本地免费出图）

## 一句话

在 Windows 本机的 ComfyUI 上跑通文生图 / 图生图，**不花云端 API 的钱**，覆盖"装不上、下不动、显存爆"这三个卡点。

## 什么时候用

- 想本地免费出图，不想按张付费；
- 已有 ComfyUI 但卡在某个环节（模型下载、显存不足、工作流跑不通）；
- 要做多镜头故事板，需要角色 / 风格跨图一致。

**不适用**：没有 NVIDIA 显卡、显存小于 8GB、或只需要偶尔出一两张图的场景——那种情况用在线工具更省事。

## 它解决的具体麻烦

| 麻烦 | 技能里的对策 |
|---|---|
| 模型 20GB+ 下到一半断 | 分段并行下载（`scripts/dl-seg.sh`），断了续传而不是重下 |
| 8GB 显存装不下全精度 | 用 NVFP4 量化模型 + 低显存启动参数 |
| 角色每张脸都不一样 | 先出设定稿，再用 img2img 锁脸 |
| 打不开界面 | 访问 `http://127.0.0.1:8188`，**不要用 localhost**（可能解析到 IPv6 `::1` 或被代理拦） |
| 跑完才发现参数不对 | 工作流以 API JSON 形式保存，可用脚本批量调，不靠手点 |

## 它怎么做

1. **先确认部署现状**：`SKILL.md` 有一张"参考部署"表，列出需要确认的每一项（ComfyUI 目录、venv、Python 版本、启动入口、工作流文件、出图目录、模型目录）。**换机器时这张表每一项都要重写**，它是清单不是抄本。
2. **按需装模型**：Z-Image-Turbo 系列工作流已在 `references/` 里给了三个 JSON（文生图 / img2img 锁脸 / 九宫格）。
3. **用脚本出图**：`scripts/comfy_gen.py` 走 API 批量生成；`scripts/gen.py` / `gen_episodes.py` / `gen_grid.py` 分别对应单张、分集、九宫格。
4. **合成视频**：`scripts/make_video.py` 把分镜图拼成 MP4。

## 边界

- **Windows + NVIDIA 专用**。macOS、AMD 卡、纯 CPU 的路径没验证过。
- **8GB 显存是硬约束**：超过这个分辨率的采样会 OOM，技能里给的是降级方案，不是"优化后能跑 4K"。
- **不保证画面质量**。它保证流程能跑通、参数可复现，不保证生成的图好看。
- 模型许可各不一样，**商用前自己看 LICENSE**，本仓库不代你判断。

## 怎么验

```bash
python skills/comfyui-local-zimage/scripts/comfy_gen.py --help
```

服务没起来时脚本会失败——先确认 `http://127.0.0.1:8188` 能打开，再跑脚本。**这是最常见的失败原因，不是脚本坏了。**

## 最常见的三个错

1. **用 localhost**。改成 `127.0.0.1` 立刻好。
2. **照抄别人机器的工作流**。节点 ID 与模型文件名在不同 ComfyUI 版本间会变，导入后要重新指认模型。
3. **显存爆了还在加分辨率**。8GB 卡应在低分辨率出图再放大，不要一步到位。
