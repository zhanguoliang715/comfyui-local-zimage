# 技术文档 · comfyui-local-zimage

**定位** 本地出图能力封装（独立技能，不属任何流水线）｜**平台** Windows + NVIDIA｜**实测环境** RTX 5060 Laptop 8GB

## 1. 定位

把 ComfyUI 的"节点式操作"封装成命令行可调用的接口，使 Agent 能批量、可复现地出图与合成视频。核心价值不是"教你装 ComfyUI"，而是**把踩过的坑固化成参数与顺序**。

## 2. 输入契约

| 项 | 要求 |
|---|---|
| 运行环境 | Windows，NVIDIA 显卡，显存 ≥ 8GB，已部署 ComfyUI |
| 服务状态 | `http://127.0.0.1:8188` 可访问（**不要用 localhost**） |
| 工作流 | `references/` 下的 API 格式 JSON；导入后需重新指认模型文件名 |
| 提示词 | 文本；多镜头场景需先产出角色设定稿再 img2img |

## 3. 输出契约

- 图像：默认写入 ComfyUI 的 `output/`，可由脚本参数改
- 视频：`make_video.py` 输出 MP4，帧序列来自分镜图
- 命名与目录按脚本参数决定，**不写死本机路径**（见「可移植性」）

## 4. 脚本与判定逻辑

| 脚本 | 职责 | 失败信号 |
|---|---|---|
| `comfy_gen.py` | 提交工作流到 API，轮询取回结果 | 连不上服务 / 节点 ID 不存在 / 模型缺失 |
| `gen.py` | 单张生成 | 同上 |
| `gen_episodes.py` | 按分集批量生成 | 分集配置缺失 |
| `gen_grid.py` | 九宫格拼版 | 源图数量不足 |
| `make_video.py` | 分镜图合成 MP4 | ffmpeg 缺失 / 帧尺寸不一致 |
| `dl-seg.sh` | 模型分段并行下载 | 断点续传校验失败 |

脚本**不做静默降级**：服务不可达时直接报错退出，避免"以为在跑其实没跑"。

## 5. 可移植性

`SKILL.md` 里那张部署表是**作者机器的实测记录**，不是模板。换机器时以下每一项都要重写：

ComfyUI 目录、venv 路径、Python 版本、启动入口、工作流文件名、出图目录、模型目录。

判据：**表里出现盘符的地方，就是需要你改的地方。**

## 6. 能力边界

**能做**：文生图、图生图锁脸、九宫格、批量分集、分镜拼视频、断点续传下载。

**不能做**：跨机器一致性（同一模型不同驱动版本出图会有差异）、保证画面质量、替代人工审片、模型许可判断。

## 7. 设计取舍

| 选择 | 为什么不选另一条路 |
|---|---|
| 走 API 而非 GUI 自动化 | 点节点无法批量化，也无法复现 |
| 用 API 格式 JSON 而非 UI 工作流 | UI 格式含布局信息，跨版本易失效 |
| 8GB 显存优先降分辨率再放大 | 一步到位必然 OOM，重试成本更高 |
| 服务不可达直接报错 | 静默重试会让人误以为任务在跑 |

## 8. 优缺点

**优点**：零 API 费用；批量可复现；参数与顺序被固化，换人接手不用重踩坑；工作流以 JSON 分发，不含权重，体积小。

**缺点与缓解**

| 缺点 | 影响 | 缓解 |
|---|---|---|
| 强绑 Windows + NVIDIA | 跨平台不可用 | README 与 SKILL.md 均明示，不假装通用 |
| 8GB 显存限制画质上限 | 高分辨率需二次放大 | 先低分辨率出图，再统一放大 |
| 工作流跨版本易失效 | 升级 ComfyUI 后需重指认模型 | 导入后先跑一张验证，再批量 |
| 依赖 ffmpeg | 环境缺则合成失败 | 首次运行前 `ffmpeg -version` 自检 |

## 9. 失败模式与处置

| 现象 | 根因 | 处置 |
|---|---|---|
| 脚本报连接失败 | 服务未启动 / 端口被占 / 用了 localhost | 浏览器先访问 `127.0.0.1:8188` |
| 提交成功但无输出 | 工作流里模型文件名与本机不符 | 重新指认模型，跑单张验证 |
| 出图一半 OOM | 分辨率或 batch 过大 | 降分辨率，或减 batch，再放大 |
| 视频合成报错 | ffmpeg 缺失 / 帧尺寸不一致 | 装 ffmpeg；统一缩放后重跑 |
| 下载反复失败 | 单段过大或网络抖动 | 减小分段体积，保留断点重试 |

## 10. 与其他技能的关系

**无依赖**。不调用流水线技能，也不被调用。产物（图 / MP4）可交给任意后续流程。
